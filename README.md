# Inero Movie

Downloads of Inero Movie for macOS: a reel editor that takes one idea to a published short video.

**[Download the latest version](https://github.com/vseriousv/inero-movie-releases/releases/latest)**: open the
`.dmg` and drag Inero Movie to Applications. The app is signed with a Developer ID and notarized by Apple, and it
updates itself (Inero Movie → Check for Updates…).

Requires macOS 15 or later (Apple silicon and Intel).
