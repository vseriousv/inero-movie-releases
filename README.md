# Inero Movie

A Mac video editor for reels about the tools you use. Record a window, let Claude Code, Codex or any AI agent in
the built-in terminal edit the timeline, and export a vertical reel that follows every click.

Website: [movie.inero.ai](https://movie.inero.ai)

**Latest version: 0.1.3** ([what's new](https://github.com/vseriousv/inero-movie-releases/releases/tag/v0.1.3))

## What it does

- **Screen recording** of a window or the whole screen, with your microphone, camera and system sound.
- **Auto zoom** turns a wide recording into a vertical reel: the frame follows your clicks and typing.
- **An AI agent in the editor**: Claude Code, Codex or another agent in the built-in terminal edits the reel live,
  then plays the result.
- **A full timeline**: main video, overlays, text, voice, music and sound effects, keyframes and transitions.
- **Covers** laid out by Claude with pictures from Nano Banana.
- **From an idea to a post**: a script with Claude, AI clips for each scene, post drafts, and publishing to
  YouTube, Instagram, Telegram and LinkedIn.

## Install

**[Download the latest version](https://github.com/vseriousv/inero-movie-releases/releases/latest)**: open the
`.dmg` and drag Inero Movie to Applications. Or with Homebrew:

```
brew install --cask vseriousv/tap/inero-movie
```

The app is signed with a Developer ID and notarized by Apple, and it updates itself (Inero Movie → Check for
Updates…). Requires macOS 15 or later. Free to download; the AI features use your own keys.
